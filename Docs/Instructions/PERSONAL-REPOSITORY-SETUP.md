# Repository setup

Destination: https://github.com/squid-forge/BinaryConstruct-Skybox-with-Extra-Features.git

Run `npm test`, `npm run build`, `npm run lint` and `npm run publication:check` before staging. Check `git status --short` so local archives, dependency folders and generated test captures are not included.

Main and origin are configured. Use your own Git name/email with repository-local `git config user.name` and `git config user.email` before committing. Do not use the original author's identity.

Keep LICENSE, LICENSES, CREDITS.md and third-party asset/dependency notices with the source. Use LICENSING.md for the component details.
