# Rendered feature examples

The README screenshots are generated by the built application from bundled presets:

- smoke-clouds.png: independent local cool/warm smoke clouds and internal emitters.
- nebula-jets.png: native black hole, procedural jets and galactic background.
- galactic-rim.png: band/core nebulae and band-distributed stars.

Run `node Docs/Instructions/verify-final-ui.mjs` against the production preview on port 4189 to regenerate them. Captures use a 1440 by 600 browser viewport with the 400px controls sidebar, so each sky image is 1040 by 600. Floating editor buttons are hidden for these illustrations. These are viewport screenshots, not HDR data or proof of a complete 16K export. They contain no user-uploaded reference artwork. Source asset attribution remains in CREDITS.md and the bundled notices.
